1. 只输出 JSON 数组，不要输出解释，不要输出 Markdown，不要输出代码块。
2. 每个物品必须且只能包含 3 个字段：name、aliases、description。
3. aliases 必须是字符串，不是数组；多个别称用中文逗号或英文逗号分隔。
4. 只要某个物品会在后续画面里被看到、被拿取、被递交、被观察、被强调、被当作结果证据或成为视觉焦点，就应该提取。
5. description 必须写成一个完整的中文字符串，不要换行，不要在 description 里再嵌套双引号，不要写成列表。
6. aliases 必须作为独立字段输出，不要把别称、简称、近义叫法写进 description。
7. 为了让软件后续更容易显示和生成物品，description 优先包含：物品类型、材质、颜色、形状、大小感、表面状态、是否发光、是否有纹路或机关特征、在画面里的主要用途。

9. description 里不要写人物姓名、人物动作、人物台词。
